## خلاصه‌ی شکاف‌ها بر اساس اولویت
1. **امنیت حساب (مرحله ۱):** Refresh/Logout/تغییر رمز/IP دستگاه.
2. **حسابداری (۸):** سال مالی و قفل دوره (قانون کسب‌وکار «دوره‌ی بسته سند نمی‌پذیرد» اجرا نمی‌شود).
3. **چک (۹):** خرج‌چک و بانک؛ **خرید (۷):** برگشت خرید؛ **انبار (۵):** بچ/انقضا، انبارگردانی.
4. **حقوق/مرخصی (۱۰)** — کل ماژول.
5. **کاتالوگ (۳) و قیمت (۴):** API برند/دسته، واحدها، پله‌ای/کمپین، `quote`.
6. UI انبار و بقیه، PDF فاکتور.
