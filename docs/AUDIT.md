## شکاف‌های باقی‌مانده نسبت به پرامپت جامع (از TODO.md و COVERAGE.md)
- **امنیت:** refresh token چرخشی؛ توکن هنوز در localStorage (کوکی HttpOnly+CSRF نیست)؛ CSP هنوز `unsafe-inline` دارد.
- **حسابداری/خزانه:** PostingTemplate قابل‌تنظیم؛ مغایرت‌گیری بانک؛ چک برگشتی با هزینه؛ کنترل موجودی بانک هنگام وصول چک پرداختی.
- **انبار/خرید:** بچ/انقضا، انبارگردانی، ضرایب تبدیل واحد، تسهیم هزینه‌ی گمرک، بازمحاسبه‌ی میانگین بها در برگشت خرید.
- **قیمت:** کمپین زمان‌دار، سقف تخفیف دستی به‌ازای نقش.
- **HR:** قرارداد، شیفت/چارت، بیمه/مالیات حقوق، اضافه‌کار، پورسانت→حقوق، فیش PDF.
- **زیرساخت:** صف روی Redis/Celery (فعلاً BackgroundTasks)، rate-limit مشترک بین workerها، حذف معاملات بین‌شرکتی در Consolidation، Sentry/Grafana، mypy/eslint.
- **فرانت:** اپ React (`frontend/`) نوشته شده ولی هرگز build نشده؛ وب قدیمی (`web/`) هنوز اصلی است.
- **مستندات:** `docs/MIGRATIONS.md` به `app/main.py` اشاره می‌کرد (اصلاح شد)؛ `COVERAGE.md` قدیمی‌تر از مراحل ۱۹–۲۰ است و باید با TODO.md هم‌خوان شود.
