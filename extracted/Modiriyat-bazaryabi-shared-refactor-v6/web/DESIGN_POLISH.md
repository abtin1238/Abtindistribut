# بهبود طراحی پنل وب (polish)

لایهٔ جدید: `web/styles/polish.css` (آخرین import در `index.css`، نسخهٔ کش v=16). همهٔ قواعد زیر `.ads` هستند و فقط پنل وب را تغییر می‌دهند (اپ‌های موبایل دست‌نخورده‌اند).

- موبایل/تبلت: رفع سرریز افقی داشبورد، منوی قرص‌شکل چسبان، هیروی بدون فضای خالی.
- سایدبار: جداکنندهٔ بخش‌های فرعی، hover/active/focus، چسبان در دسکتاپ.
- جدول‌ها: پنل با سربرگ چسبان و hover ردیف؛ آمار و فیلترها در موبایل جمع‌وجور.
- داشبورد: رنگ و آیکون معنادار برای هر نوع فعالیت، آیکون تقویم، حرکت ورودی ملایم (با احترام به reduced-motion).
- تنظیمات: عرض خوانا، انتخاب‌گر رنگ جمع‌وجود، برچسب اسلایدرها یک‌خطی.
- تم روشن: متن هیرو خوانا شد.
