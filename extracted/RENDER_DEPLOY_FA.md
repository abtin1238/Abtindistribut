# استقرار آزمایشی روی Render

این مخزن برای شروع تست روی Render آماده شده است. فایل `render.yaml` یک Web Service با Docker و یک PostgreSQL ایجاد می‌کند و رمز مدیر را به‌صورت خودکار تولید می‌کند.

## روش اجرا
1. محتویات این پوشه را در ریشه یک مخزن GitHub قرار دهید (خود پوشه والد نباید یک لایه اضافه ایجاد کند).
2. در Render از **New + → Blueprint** مخزن را انتخاب کنید و تنظیمات `render.yaml` را اعمال کنید.
3. قبل از تأیید، بررسی کنید هر دو سرویس روی پلن Free باشند؛ سپس Apply/Deploy را اجرا کنید.
4. رمز مدیر در Environment Variables سرویس وب، در متغیر `ADMIN_PASSWORD` تولید می‌شود. آن را محرمانه نگه دارید.
5. بعد از Deploy، نشانی `https://...onrender.com/web/` را باز کنید؛ API در همان دامنه اجرا می‌شود.

## محدودیت تست رایگان
- سرویس وب رایگان در بی‌کاری ممکن است متوقف شود و اولین درخواست بعدی کند باشد.
- دیتابیس رایگان Render موقت است و طبق شرایط Render ممکن است پس از دوره آزمایشی حذف/منقضی شود؛ اطلاعات مهم وارد نکنید.
- فایل‌های آپلودشده در فضای موقت سرویس وب ممکن است پس از راه‌اندازی مجدد یا استقرار از بین بروند.
- این بسته در این محیط با Docker اجرا نشده است؛ پیکربندی برای Render اضافه شده اما Deploy واقعی هنوز باید در Render تأیید شود.
